# Simple Calculator in C

## About the Project
This is a simple calculator program developed using the C programming language. It performs basic arithmetic operations on two numbers.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (* )
- Division (/)
- Modulus(%)
- User-friendly console interface
- Takes input from the user

## Technologies Used
- C Programming Language
- Standard Input/Output (`stdio.h`)

## How to Run
1. Download or clone this repository.
2. Open the C file in any C compiler.
3. Compile the program.
4. Run the executable.
5. Enter two numbers and select an operation.

## Sample Output

```text
===== Simple Calculator =====

Enter first number: 10
Enter second number: 5

Addition: 15
Subtraction: 5
Multiplication: 50
Division: 2
```
